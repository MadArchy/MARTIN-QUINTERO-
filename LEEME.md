# Cómo ver la página correcta

## URL correcta

Abre exactamente esta dirección:

**http://localhost:3000**

Si ves algo distinto, probablemente estabas en la versión vieja de Next.js.

## Forma más fácil

1. Doble clic en `ABRIR-PAGINA.bat`
2. Se abrirá el navegador con la página HTML/CSS/JS

## También puedes abrir el archivo

`web/index.html`

## Si no ves cambios

1. Cierra todas las pestañas de `localhost`
2. Abre de nuevo: http://localhost:3000
3. Pulsa `Ctrl + F5` (recarga forzada sin caché)

## Dónde está el código

- HTML: `web/index.html`
- CSS: `web/css/styles.css`
- JS: `web/js/main.js` y `web/js/data.js`
- Imagen de referencia: `martin_cursor_referencias/diseno_web_referencia.png`
