# Martín Soldadura Especializada — HTML / CSS / JavaScript

Sitio estático fiel a la referencia visual. Sin React ni Next.js.

## Abrir

Opción A — doble clic:

```text
web/index.html
```

Opción B — servidor local:

```bash
cd web
npx --yes serve -l 8080
```

Luego abre: http://localhost:8080

## Editar datos

Archivo: `js/data.js`

- WhatsApp, teléfono, dirección, redes
- Servicios, ventajas y proyectos
- Textos de cotización

## Imágenes

Carpeta: `images/`

Reemplaza las fotos provisionales por material real de la empresa. El logo en `images/branding/logo-martin.png` es el original.
